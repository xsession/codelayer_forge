# Embeddyn Project Identity

**Embeddyn** is the unified name for the mechatronic emulation, co-simulation, HIL, and digital-twin platform previously developed under the Visual System Designer / VSD project identity.

## Naming

- Product: **Embeddyn**
- Python distribution: `embeddyn`
- Python package: `embeddyn`
- Primary CLI: `embeddyn`
- Local data directory: `embeddyn`
- Primary environment-variable prefix: `EMBEDDYN_`
- Compatibility CLI alias: `vsd`

## Scope

Embeddyn unifies firmware emulation, electrical simulation, mechanical simulation, engineering-tool integration, distributed experiments, HIL safety, and digital-twin workflows in one versioned engineering platform.

## Compatibility

The `vsd` command remains as a compatibility alias. Core runtime configuration prefers `EMBEDDYN_*` environment variables while accepting the previous `VSD_*` names during migration. New projects and documentation should use only the Embeddyn names.

## Upstream attribution

The repository retains the original copyright notices and licenses of upstream components and the Visual System Designer codebase from which parts of Embeddyn evolved. Rebranding does not alter those notices or license obligations.
