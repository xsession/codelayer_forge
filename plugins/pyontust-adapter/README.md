# PyOnTrust Adapter

The exact public contract of `pyontust` was not available when this repository was generated. This plugin therefore provides a secure, useful integration seam instead of inventing domain behavior.

It executes declarative workflows with an allowlist of non-shell actions: validate JSON, render a template, write JSON and copy a workspace file. Replace or extend these actions behind the same versioned capability once the actual PyOnTrust API is supplied.
